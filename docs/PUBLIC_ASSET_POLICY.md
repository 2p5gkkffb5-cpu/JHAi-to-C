# 公开素材策略

本公开仓库只分发项目源码、仓库自有品牌文件和明确随仓库授权的中性占位图。

私有开发仓库曾为界面还原和本地验证保存外部页面资源、发现页内容及用户上传示例。它们不属于公开源码交付，也不因本项目采用 MIT License 而获得重新授权，因此不会进入公开仓库或 Git 历史。

公开版遵循以下规则：

- `apps/web/public/source-assets/` 永久排除并由发布树检查阻止跟踪；
- 界面示例卡片和图标使用 `apps/web/public/brand/public-placeholder.svg`；
- 真实用户上传图片、视频、Provider 输出和本地数据库不得作为演示素材提交；
- 后续新增截图或示例素材时，必须记录原创者、授权条款和允许的分发范围；
- 品牌名称与标识的商标权不因 MIT 代码许可证自动授予。

如果贡献者无法确认素材来源或再分发权，应使用中性占位图或在本地 `.gitignore` 范围内验证，不得提交到公开仓库。
