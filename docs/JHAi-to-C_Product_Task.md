# AI 内容生产 Agent 融资 Demo 执行任务书

## 项目目标

实现一个融资展示级 AI 内容生产 Demo。

参考方向：

-   DAAI
-   内容特工队
-   Manus 类 Agent 工作流

目标：

1.  一句话需求驱动完整内容生产流程。
2.  多 Agent 协作完成营销内容生成。
3.  展示区别于普通 AI 视频生成工具的产品能力。
4.  为后续企业级 AI 内容生产平台打基础。

------------------------------------------------------------------------

## 技术路线

Agent 编排：

使用 LangGraph。

不要引入：

-   CrewAI
-   AutoGen
-   Microsoft Agent Framework
-   Dify Runtime
-   Flowise Runtime
-   langgraph-supervisor 封装

原因：

项目需要：

-   状态控制
-   节点重跑
-   审核循环
-   人工介入
-   后续接入现有业务系统

------------------------------------------------------------------------

# Agent 设计

## Director Agent

负责：

-   理解用户需求
-   判断工作流
-   生成 Creative Brief

输出：

``` json
{
  "industry":"",
  "product":"",
  "platform":"",
  "goal":"",
  "target_audience":"",
  "content_direction":"",
  "workflow_type":""
}
```

------------------------------------------------------------------------

## Research Agent

负责：

-   市场分析
-   用户洞察
-   内容趋势

Demo 阶段允许 Mock 数据。

输出：

``` json
{
 "audience_insight":[],
 "competitor_pattern":[],
 "content_trend":[],
 "suggestions":[]
}
```

------------------------------------------------------------------------

## Strategy Agent

生成多个营销方向。

例如：

-   爆汁视觉冲击
-   品牌故事
-   用户体验

输出：

方案名称、Hook、结构、原因。

------------------------------------------------------------------------

## Production Agent

包含：

### Copywriting Node

生成：

-   标题
-   前三秒 Hook
-   口播
-   字幕
-   CTA

### Storyboard Node

生成：

-   镜头
-   时长
-   画面
-   动作
-   摄像
-   提示词

------------------------------------------------------------------------

## Reviewer Agent

检查：

-   需求匹配
-   平台适配
-   CTA
-   逻辑完整性
-   视频生成可执行性

失败：

返回对应节点。

最多循环两次。

------------------------------------------------------------------------

# 验收标准

必须满足：

1.  用户输入一句需求。
2.  多 Agent 自动执行。
3.  用户能看到执行过程。
4.  能生成营销方案。
5.  能生成文案。
6.  能生成分镜。
7.  Reviewer 可以审核。
8.  最终展示视频结果。
9.  架构支持未来扩展。
10. 不引入大量无关依赖。
